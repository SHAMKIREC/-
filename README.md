# Рядом · NRV

Единое React + TypeScript + Vite приложение для локальных заказов. Первый район: Саратов, 3-я Дачная.

- Сайт: https://shamkirec.github.io/-/
- Изолированная проверка без регистрации: https://shamkirec.github.io/-/#test
- Защищённый вход владельца: https://shamkirec.github.io/-/#owner

Публичный каталог загружает только одобренные активные заведения из Supabase. Примеры меню доступны исключительно в тестовой среде. Она хранит свои операции в браузере и не отправляет их в производственную базу. Права владельца определяются базой, адрес маршрута их не даёт.

## Разработка

Node 22. Установка: `npm ci`. Проверки: `npm run typecheck`, `npm run build`. Локально: `npm run dev` и путь `/-/`.

В `src/lib/marketplace-api.ts` используется один клиент Auth. Публичный ключ допустим во фронтенде. Переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` могут переопределить настройки. Секретные ключи во фронтенд и Git не добавлять.

## Проверки

Сборка включает проверку TypeScript и наличие опубликованных JS/CSS с правильным base. GitHub Actions использует lockfile и проверяет PR до слияния. `tests/security-workflow.sql` проверяет серверный цикл, RLS и запрет повышения прав внутри транзакции с rollback. Выполнять через SQL-инструмент с достаточными правами в тестовой среде.
